Dúvidas frequentes

Transparência desde o começo

O ViraChave já é um serviço financeiro ativo?

Não. Esta versão é um protótipo visual usado para avaliar navegação e experiência. Autenticação, banco de dados, pagamentos e assistente de IA não estão conectados.

Os valores e gráficos são reais?

Não. Os dados visuais da plataforma são exemplos ilustrativos. A calculadora da página usa apenas os valores que você informar nesta sessão e faz uma subtração simples.

O sistema garante que vou quitar minhas dívidas?

Não. Resultados dependem da situação de cada pessoa, dos juros e das condições dos credores. O propósito é apoiar organização e comparação de cenários, sem garantia de resultado.

Como serão tratados meus dados?

Esta demonstração não cria uma conta real nem envia seus dados financeiros para o servidor. Antes de uma versão funcional, a política de privacidade, os controles de segurança e os procedimentos de tratamento de dados deverão ser implementados e revisados.
